# Dice Game 12 :tada:

This project was developed as part of an introductory Java programming course. It focuses on fundamental programming concepts such as methods, conditional logic, loops, and state management.

Dice Game 12 is a console-based game where the player rolls three dice, one at a time, and tries to get a total sum of exactly 12.

## Game Rules 🎲

- Enter 1, 2, or 3 to roll the corresponding die.

- Each die can only be rolled once per round, and the dice can be selected in any order.

- The result is determined only after all three dice have been rolled.

- A total sum of exactly 12 is a win.

- A total sum greater than 12 is a loss.

- A total sum below 12 results in neither a win nor a loss.

- Enter q to quit the game.

## Features :sparkles:

- Random dice rolls from 1 to 6

- Input validation and handling of invalid entries

- Prevention of repeated rolls within the same round

- Automatic round resets after all three dice have been rolled

- Score tracking for wins and losses across multiple rounds

## Concepts Practiced

- Java methods and return values

- Constants and variables

- Conditional statements and switch

- Loops and game flow

- Random number generation with Random

- Input validation using Scanner

- Managing game state and tracking scores
